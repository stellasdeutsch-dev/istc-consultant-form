    Saving vs publishing

    Edits save to this browser as you type — nobody else sees them yet. To make them live, press Publish…, then commit the downloaded form-schema.js to the repository (replacing the existing file). Reset discards local edits and shows the published form again.

    This page is not a security boundary

    The site is static, so admin.html is reachable by anyone who knows the URL, and nothing here can be locked behind a password in the browser alone. It changes only what the form asks; it cannot read submissions. Keep the URL internal, and rely on the repository's write access as the real control over what goes live.
